# 🚀 Portafolio de Fundamentos de Programación - Desarrollo Full-Stack

¡Hola! Bienvenido a mi espacio de desarrollo técnico. Soy un apasionado de la tecnología en formación activa como **Programador Full-Stack**, enfocado en desarrollar un pensamiento analítico, lógico y orientado a resolver problemas reales mediante código limpio.

Este repositorio contiene el despliegue ordenado de mis primeros laboratorios prácticos y algoritmos tras completar con éxito un entrenamiento intensivo de **21 días de pseudocódigo y lógica pura**.

---

## 📁 Estructura del Repositorio

Para demostrar orden y buenas prácticas de arquitectura de software, he clasificado mis proyectos en tres bloques fundamentales:

*   **`01_Condicionales/`**: Algoritmos basados en la toma de decisiones complejas utilizando estructuras condicionales (`Si... Entonces`, `Segun`) y operadores lógicos (`Y`, `O`, `NO`). Incluye simuladores de cajeros automáticos, controles de acceso y lógica de validación de procesos.
*   **`02_Ciclos_Repetitivos/`**: Laboratorios enfocados en la automatización de tareas cíclicas mediante bucles (`Mientras`, `Para`). Aquí destaca el diseño de scripts automatizados para simulación de flujos e iteraciones de seguridad.
*   **`03_Ejercicios_Libres/`**: Programas secuenciales de base, manipulación matemática de variables, operadores aritméticos fundamentales y flujos de datos introductorios.

---

## 🛠️ Tecnologías y Herramientas Evaluadas
*   **Lógica de Programación**: Construcción de algoritmos robustos y diagramas de flujo utilizando **PSeInt**.
*   **Control de Versiones**: Arquitectura básica de repositorios y gestión de código mediante **Git y GitHub**.
*   **Metodología**: Enfoque disciplinado, estructuración jerárquica de archivos y documentación técnica clara (Clean Code).
